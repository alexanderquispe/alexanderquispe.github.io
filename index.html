Research

Working papers

Agentic Delegation and the Language Frontier of Software Developers: A Model and Evidence from Claude Code on GitHub
Alexander Quispe, Kevin Xu · 2026 · arXiv

When developers adopt Claude Code, the set of programming languages they work in roughly triples, and first uses of unfamiliar languages concentrate among narrow specialists.

Agentic AI and the Industry Composition of Developer Work
Alexander Quispe, Kevin Xu · 2026 · draft

Around first Claude Code use, developers' public work spreads into new industries: monthly distinct sectors nearly triple, and the cumulative sectoral footprint stays about 50% higher.

Renting Intelligence: Student Responses to an Exogenous Downgrade in AI Model Quality
Alexander Quispe, Kevin Xu · 2026 · draft

When GitHub moved students from Copilot Pro to a plan without premium models, their AI-assisted commits fell by roughly 83% of the pre-period mean relative to matched controls.

A Unified Economic Model of Agentic Coding Automation
Alexander Quispe · 2026 · draft

How many coding agents can an organization run? The tightest of verification, isolation, and demand constraints sets the scale, and the practitioners' five maturity stages correspond to which one binds.

Impact of the Availability of ChatGPT on Software Development: A Synthetic Difference in Differences Estimation using GitHub Data
Alexander Quispe, Rodrigo Grijalba · 2023 · arXiv

Using government bans of ChatGPT as natural experiments, we find that access raised git pushes, repositories, and developers per capita on GitHub.
