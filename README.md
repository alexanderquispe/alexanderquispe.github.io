# alexanderquispe.github.io

Personal website of Alexander Quispe — <https://alexanderquispe.github.io>.

**The live site is built by GitHub Pages from this `ss` branch.** (`master` holds an older, unused template.)

| Path | What it is |
| --- | --- |
| `index.html` | Homepage (bio, papers, software, news, teaching) |
| `_posts/` | Blog posts, `YYYY-MM-DD-title.md` (comments via giscus) |
| `_drafts/` | Unpublished posts (move to `_posts/` with a date to publish) |
| `teaching/` + `_data/teaching.json` | Student pages for each course |
| `cv.pdf` | Current CV — replace this file to update it; the URL never changes |
| `files/` | Paper drafts and other PDFs linked from the homepage |
| `_config.yml` | Site settings, social links, giscus IDs |
| `css/site.css` | All styles (light + dark) |

Preview locally: `bundle exec jekyll serve` (Jekyll 3.10 with `jekyll-feed`, `jekyll-seo-tag`, `jekyll-sitemap`).
