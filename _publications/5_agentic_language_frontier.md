excerpt: 'With Kevin Xu (GitHub). We model agentic AI as adding a delegation mode to software production that lowers language-specific entry thresholds, creating an activation band of newly feasible languages. In commit-level staggered-adoption event studies on GitHub (Callaway–Sant&apos;Anna), Claude Code adopters use 2.5 more programming languages at adoption on a 0.9 baseline and enter 1.2 languages absent from their entire prior history; the expansion survives excluding all Claude-co-authored commits and concentrates among pre-adoption specialists at every activity level. Working paper, 2026.'
