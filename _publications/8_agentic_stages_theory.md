excerpt: 'A unified model of agentic software production: an organization chooses agent scale, self-verification intensity, and independent-verification coverage subject to human review capacity, isolation capital, and finite useful demand. Verification is a layered acceptance technology with a correlated-error floor — an agent that misreads a specification can write both the wrong code and the test that approves it — so only independent verification can drive false acceptance to zero. The implementable agent scale is min{unconstrained scale, verification ceiling, isolation ceiling, demand ceiling}, and the five practitioner maturity stages (gated, assisted, parallel, supervised autonomy, AI-native) emerge as the identity of the binding constraint. All derivations machine-verified in sympy. Working paper (draft), 2026.'
